## IwaraTV 2.0

> [!WARNING]
> **2.0 is a breaking release.** It replaces the app's runtime, so it doesn't update 1.x in place on Windows, needs a newer macOS, and asks you to sign in again. Read **Breaking changes** below before upgrading.

IwaraTV has been rebuilt on Electron with a redesigned interface. Highlights:

- **Built-in player** — press **Play here** on any video; no MPV needed. It remembers where you stopped, switches quality without losing your place, and has fullscreen and keyboard controls. MPV and external players are still one click away.
- **Continue watching**, hover previews of video frames, related videos and more from the author on every video page.
- Recent searches and copied-link suggestions in the top bar, a shortcut list (press `?`), compact cards, download progress on the taskbar and completion notifications.
- English and Simplified Chinese, light and dark themes, clearer errors with one-click fixes.
- Hardened security: sandboxed interface, strict content security policy, isolated Iwara sign-in window. See the [audit report](https://github.com/demogest/IwaraTV/blob/main/docs/audit.md).

### ⚠️ Breaking changes

- **New runtime.** IwaraTV now runs on Electron (Chromium) instead of Tauri (the system web view). System requirements follow Electron 44: **Windows 10 or later (64-bit)**, **macOS 13 Ventura or later on Apple Silicon**, and 64-bit Linux. macOS 12 and older, which 1.x supported, can't run 2.0 — stay on 1.0.2 there.
- **Sign in again.** Iwara sessions and the API token 1.x kept in the system keyring aren't carried over (the keyring entry is no longer used and can be deleted).
- **New data folder.** Settings, favorites and history move from `local.iwaratv.player` to an `IwaraTV` folder (`%APPDATA%\IwaraTV`, `~/Library/Application Support/IwaraTV`, `~/.config/IwaraTV`). They're copied once on first start; the 1.x files are left as they were, so going back to 1.x keeps its own data.
- **Windows installs as a new app.** The 2.0 installer doesn't replace 1.x and uses a new install location. Uninstall 1.x first (see below).
- **Release file names changed** for scripts that download by name: the macOS image is `…_arm64.dmg` (was `…_aarch64.dmg`) and the AppImage is `…_x86_64.AppImage` (was `…_amd64.AppImage`). The Linux package now installs to `/opt/IwaraTV` with `/usr/bin/iwaratv` as a link, and its launcher is `iwaratv.desktop`.
- **New installs play videos in the built-in player** by default. Existing settings keep MPV or your external player.
- **For contributors:** the Rust/Tauri toolchain and `src-tauri` are gone. `npm run dev` now starts the desktop app; `dev:tauri`, `build:tauri`, `build:web`, `release:portable:win` and `release:win:fast` are removed (see `CONTRIBUTING.md`). Favorites exports keep the same format and import into either version.

### Upgrading from 1.x

- Your settings, favorites and download history are imported automatically on first start. **Sign in again once** — sessions can't be carried over.
- **Windows:** uninstall IwaraTV 1.x first (Settings → Apps), and leave "delete the application data" unchecked so your data can be imported. Then run the 2.0 installer.
- **macOS:** replace the app in Applications. The app isn't notarized: the first time, right-click it and choose **Open**.
- **Linux:** the `.deb` upgrades the 1.x package in place.
- Your default player stays MPV (or your external player). Switch to **Built-in** in Settings → Playback if you like.

### ⚠️ 不兼容变更（中文摘要）

- **运行时更换**：改为基于 Electron（Chromium）。系统要求：**Windows 10 及以上（64 位）**、**macOS 13 Ventura 及以上（Apple 芯片）**、64 位 Linux。macOS 12 及更早版本无法运行 2.0，请继续使用 1.0.2。
- **需要重新登录**：Iwara 会话及 1.x 保存在系统钥匙串中的令牌不会迁移（该钥匙串条目已不再使用，可删除）。
- **数据目录变更**：设置、收藏和历史从 `local.iwaratv.player` 迁移到 `IwaraTV` 目录，首次启动时复制一次；1.x 的文件保持不变。
- **Windows 作为新应用安装**：2.0 安装程序不会替换 1.x，并使用新的安装位置，请先卸载 1.x。
- **发布文件名变更**：macOS 镜像改为 `…_arm64.dmg`（原 `…_aarch64.dmg`），AppImage 改为 `…_x86_64.AppImage`（原 `…_amd64.AppImage`）。Linux 软件包改为安装到 `/opt/IwaraTV`，并以 `/usr/bin/iwaratv` 链接启动。
- **新安装默认使用内置播放器**；已有设置保持 MPV 或外部播放器。

### 升级说明（1.x → 2.0）

- 首次启动会自动导入设置、收藏和下载记录，需要**重新登录一次**。
- **Windows：**请先卸载 IwaraTV 1.x（设置 → 应用），不要勾选“删除应用数据”，以便导入数据；然后运行 2.0 安装程序。
- **macOS：**替换“应用程序”中的 IwaraTV。应用未经公证，首次打开请右键点击并选择**打开**。
- **Linux：**`.deb` 会直接升级 1.x 软件包。
- 默认播放器保持为 MPV（或外部播放器），可在 设置 → 播放 中切换为**内置**。
