## IwaraTV 2.1

IwaraTV now keeps itself up to date.

- **Updates inside the app.** IwaraTV checks GitHub for a new version when it starts and every 6 hours. When one is out, an item above **Settings** in the sidebar shows what's new.
- **As little effort as your install allows.** The Windows installer and the AppImage download updates in the background and install them when you choose **Restart to update**. Portable, ZIP, `.deb` and macOS copies download the update and open it, or show it in its folder, for you to finish.
- **Checked before anything runs.** Releases are signed, and IwaraTV verifies the signature and every file's checksum before installing. Breaking releases are never installed automatically, and you can skip a version.
- **Settings → Updates** checks on demand, turns automatic checks or background downloads off, and shows how your copy updates. Update checks contact only github.com, without cookies or anything that identifies you.

### Upgrading from 2.0

2.0 can't update itself, so install 2.1 the usual way once. Later versions then reach you from inside the app.

- **Windows:** run the 2.1 installer. It updates 2.0 in place and keeps your data. For the portable app, replace the `.exe`.
- **macOS:** replace the app in Applications. It isn't notarized, so the first time you open it, go to **System Settings → Privacy & Security** and click **Open Anyway**. On macOS 13 and 14 you can instead right-click the app and choose **Open**.
- **Linux:** install the `.deb` over 2.0, or replace the AppImage.

### 2.1 更新内容（中文摘要）

- **应用内更新**：IwaraTV 会在启动时和之后每 6 小时检查 GitHub 上的新版本，有新版本时侧边栏的**设置**上方会显示提示。
- Windows 安装版和 AppImage 会在后台下载更新，点击**重启以更新**即可完成；便携版、ZIP、`.deb` 和 macOS 版会下载更新并打开（或在文件夹中显示），由你完成安装。
- 发布经过签名，安装前会校验签名和每个文件的校验和；不兼容更新绝不会自动安装，也可以跳过某个版本。
- **设置 → 更新**可立即检查、关闭自动检查或后台下载。检查更新只访问 github.com，不发送 Cookie 或任何可识别你的信息。
- **从 2.0 升级**：2.0 无法自动更新，请像往常一样手动安装一次 2.1，之后的版本会在应用内推送。macOS 首次打开时请前往**系统设置 → 隐私与安全性**并点击**仍要打开**（macOS 13 和 14 也可以右键点击应用并选择**打开**）。
