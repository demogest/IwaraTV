## IwaraTV 2.4

### New

- **Multi-thread downloader.** Each file downloads over up to 16 connections at once, written straight into one file, so there is no extra copy step when it finishes.
  - A connection that finishes early takes over half of the largest part still downloading, so one slow connection no longer holds up the end.
  - Dropped connections, and connections that get no data for 30 seconds, reconnect on their own and continue where they stopped. If the server turns extra connections away, the download carries on with fewer.
  - **Resume** continues where a download stopped, also after a crash or restart; the missing parts are tracked in a small `.part.json` file next to the `.part` file.
- **Simultaneous downloads.** Choose how many downloads run at once (1–5) in **Settings → Downloads**; the rest wait in the queue and start as others finish.
- Download rows show how many connections are in use, and the progress bar shows each part of the file filling in.

### Changed

- **Connections per download** now goes up to 16. New installs use 8; if you changed download settings before, your current value is kept — raise it in **Settings → Downloads**.
- A download interrupted in an earlier version while using several connections starts over once. Single-connection partial downloads continue where they stopped.

### Updating

IwaraTV 2.1 and later offer this update themselves: the Windows installer and AppImage download it in the background (choose **Restart to update**); portable, ZIP, `.deb` and macOS copies download it when you click **Download**. From 2.0, install it by hand once.

### 中文摘要

- **多线程下载**：每个文件最多通过 16 个连接同时下载，直接写入同一个文件，完成时无需再合并。
  - 先完成的连接会接手仍在下载的最大部分的后一半，不会因为某个连接慢而拖慢整体。
  - 断开或 30 秒没有数据的连接会自动重连并从中断处继续；服务器拒绝多余连接时，会用较少的连接继续下载。
  - **继续**会从中断处接着下载，崩溃或重启后也可以；尚缺的部分记录在 `.part` 文件旁的 `.part.json` 中。
- **同时下载数**：可在**设置 → 下载**中设置同时进行的下载数（1–5），其余的会排队，等前面的完成后自动开始。
- 下载列表显示正在使用的连接数，进度条会显示文件每个部分的进度。
- **每个下载的连接数**最多可设为 16。新安装默认 8；之前改过下载设置的会保留原值，可在**设置 → 下载**中调高。
- 旧版本中使用多个连接、尚未完成的下载会重新开始一次；单连接的未完成下载会从中断处继续。
- 2.1 及以上版本会在应用内提示此更新。

### 繁體中文摘要

- **多執行緒下載**：每個檔案最多透過 16 個連線同時下載，直接寫入同一個檔案，完成時不必再合併。
  - 先完成的連線會接手仍在下載的最大部分的後半段，不會因為某個連線慢而拖慢整體。
  - 中斷或 30 秒沒有資料的連線會自動重新連線並從中斷處繼續；伺服器拒絕多餘連線時，會以較少的連線繼續下載。
  - **繼續**會從中斷處接著下載，當機或重新啟動後也可以；尚缺的部分記錄在 `.part` 檔案旁的 `.part.json` 中。
- **同時下載數**：可在**設定 → 下載**中設定同時進行的下載數（1–5），其餘的會排入佇列，等前面的完成後自動開始。
- 下載清單會顯示使用中的連線數，進度列會顯示檔案每個部分的進度。
- **每個下載的連線數**最多可設為 16。新安裝預設為 8；之前改過下載設定的會保留原值，可在**設定 → 下載**中調高。
- 舊版本中使用多個連線、尚未完成的下載會重新開始一次；單一連線的未完成下載會從中斷處繼續。
- 2.1 以上版本會在應用程式內提示此更新。

### 日本語の概要

- **マルチスレッドダウンロード**：1 つのファイルを最大 16 本の接続で同時にダウンロードし、そのまま 1 つのファイルに書き込みます。完了時の結合処理は不要になりました。
  - 早く終わった接続が、まだダウンロード中の最も大きな部分の後半を引き継ぐので、遅い接続に全体が引きずられません。
  - 切れた接続や 30 秒間データが届かない接続は自動で再接続し、止まった位置から続けます。サーバーが追加の接続を断った場合は、少ない接続数で続行します。
  - **再開**はクラッシュや再起動の後でも止まった位置から続けます。残りの部分は `.part` ファイルの隣の `.part.json` に記録されます。
- **同時ダウンロード数**：**設定 → ダウンロード**で同時に実行する数（1〜5）を選べます。それ以上は順番待ちになり、前のものが終わると自動で始まります。
- ダウンロード一覧に使用中の接続数が表示され、進捗バーにはファイルの各部分の進み具合が表示されます。
- **1 件あたりの接続数**は最大 16 になりました。新規インストールでは 8 です。以前にダウンロード設定を変更していた場合は今の値のままなので、**設定 → ダウンロード**で上げてください。
- 以前のバージョンで複数の接続を使って中断したダウンロードは、一度だけ最初からやり直しになります。1 本の接続で中断したダウンロードは続きから再開します。
- 2.1 以降ではアプリ内でこのアップデートが案内されます。
