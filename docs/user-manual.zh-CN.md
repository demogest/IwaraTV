# IwaraTV 用户手册

简体中文 | [English](user-manual.en.md)

IwaraTV 是一个用于浏览 Iwara.tv 并观看视频的桌面应用——可以使用内置播放器，也可以使用 MPV 或电脑上的其他播放器。它保存的所有内容——设置、收藏、历史、下载和 Iwara 会话——都只存放在你的电脑上。

本项目为独立制作，不隶属于 Iwara，也未获得 Iwara 的赞助、认可或背书。

## 安装与启动

IwaraTV 支持 Windows 10 及以上（64 位）、macOS 13 Ventura 及以上（Apple 芯片）以及 64 位 Linux。

1. 从 [GitHub Releases](https://github.com/demogest/IwaraTV/releases) 下载最新版本：
   - Windows：`IwaraTV_<version>_x64-setup.exe`（安装包）、`…-portable.exe`（免安装）或 `…-unpacked.zip`。
   - macOS：`.dmg`。应用未经公证，首次打开请右键点击应用并选择**打开**。
   - Linux：`.deb` 或 `.AppImage`（先赋予可执行权限）。
2. 启动 IwaraTV。应用会直接打开浏览页，登录不是必需的。
3. 在任意视频上点击**在此播放**即可观看，内置播放器无需安装其他软件。如果你更喜欢 MPV：Windows 版本已内置；在 macOS 和 Linux 上请先安装（`brew install mpv`、`sudo apt install mpv` 等），然后在**设置 → 播放**中选择它。

从旧版（基于 Tauri）IwaraTV 升级：首次启动时会自动导入设置、收藏和下载记录，可在**设置 → 高级**中看到提示。需要重新登录一次——会话无法迁移。默认播放器仍保持为 MPV（或你的外部播放器）；如需使用内置播放器，可在**设置 → 播放**中切换为**内置**。

## 窗口布局

- **侧边栏**：浏览、搜索、订阅（发现）以及收藏、下载、历史（我的）；底部是设置和账号。标志旁的按钮可折叠侧边栏，窗口较窄时会自动折叠。“下载”上的数字表示进行中的下载数量。
- **顶部输入框**：输入文字后按回车即可搜索；粘贴 Iwara 链接或视频 ID 即可打开视频。如果内容既像搜索词又像视频 ID，候选列表会同时给出两个选项。输入框为空时，会列出最近搜索（可用 **×** 或 `Delete` 移除单条，也可全部清除）；如果你复制了 Iwara 视频链接，还会提示直接打开。
- **返回**：返回按钮、`Esc`、`Alt+←` 或鼠标侧键都能回到上一个页面，并恢复滚动位置。

键盘快捷键（按 `?` 或顶部栏的键盘按钮可在应用内查看）：

| 按键 | 作用 |
| --- | --- |
| `/`、`Ctrl+K` 或 `Ctrl+L`（macOS 为 `⌘`） | 聚焦顶部输入框 |
| `Ctrl+1` … `Ctrl+6` | 浏览、搜索、订阅、收藏、下载、历史 |
| `Ctrl+,` | 打开设置 |
| `Esc`、`Alt+←`、鼠标侧键 | 返回 |
| 评论框中按 `Ctrl+Enter` | 发送 |
| `?` | 显示快捷键列表 |
| `Space` 或 `K` | 内置播放器：播放或暂停 |
| `←` / `→` | 内置播放器：后退或前进 5 秒 |
| `F` / `M` | 内置播放器：全屏 / 静音 |
| 方向键、`Home`、`End` | 在标签页、清晰度选项和菜单项之间移动 |

## 浏览与搜索

- **浏览**有四个列表：最新、当前人气、流行视频和关注标签。分级开关（全部 / 全年龄 / Ecchi）对所有列表生效，默认值可在**设置 → 通用**中设置。添加标签筛选可缩小范围。
- **搜索**会搜索整个 Iwara，可按相关度、最新、播放最多或喜欢最多排序。
- **订阅**展示你在 Iwara 上关注的作者的新视频（需要登录）。可用顶部的作者按钮筛选。
- 鼠标停留在视频卡片上即可预览：缩略图会依次展示视频中的画面，并出现快捷操作（播放、下载、收藏）。点击作者名可打开作者页。
- 浏览页顶部的**继续观看**会列出在内置播放器中看过但尚未看完的视频；缩略图下方的进度条显示看到哪里，点击**继续播放**即可接着看。
- **设置 → 通用 → 卡片大小**可切换为小卡片，每行显示更多视频。
- 在不同页面间切换时，列表会记住页码和滚动位置。

## 观看视频

打开视频即可查看详情。先选择**清晰度**（从高到低排列），然后：

- **在此播放**（或根据默认设置显示为**用 MPV 播放** / 外部播放器）。旁边的箭头可临时改用其他播放器。
- **下载**保存所选清晰度。
- **收藏**把视频保存在本地。
- **⋯** 可在 Iwara 中打开视频或复制链接。

如果所选清晰度不可用，IwaraTV 会使用可用的最高清晰度并提示你。页面还会显示简介、标签和评论，侧栏中还有作者的**更多视频**和**相关视频**。每个标签都有菜单，可浏览、关注或屏蔽该标签。

### 内置播放器

**在此播放**会直接在视频页中播放，提供常用控件、全屏和键盘快捷键（`Space`/`K`、`←`/`→`、`F`、`M`），并会记住音量。

- 观看时切换**清晰度**，会从同一时间点继续播放。
- IwaraTV 会记住你看到的位置，下次从那里继续，并提供**从头播放**以便重新开始。已看完的视频会从头播放。
- 离开页面会停止播放；右上角的 **×** 可关闭播放器并恢复缩略图。
- 如果视频无法播放（例如链接已过期），播放器会提供**重试**；也可以通过箭头菜单改用 MPV。

### 播放器

在**设置 → 播放**中选择默认播放器和首选清晰度。如果找不到 MPV 或外部播放器，错误提示中会提供**改为在此播放**。

- **MPV**：会自动查找（内置版本、系统中的 MPV，或你指定的路径）。**测试 MPV** 可确认它能正常启动。
- **外部播放器**：选择可执行文件并填写参数。参数必须包含 `{url}`，也可以使用 `{title}` 和 `{headers}`（Iwara 的 Referer 请求头）。预览会显示实际执行的命令。

## 登录

订阅、关注作者、评论以及部分私密视频需要 Iwara 账号。

1. 在订阅页或**设置 → 账号**中点击**使用 Iwara 登录**（侧边栏底部的账号按钮会打开该设置页）。
2. Iwara 官方登录页会在独立窗口中打开。在其中登录；如果 Iwara 要求浏览器验证，请一并完成。你的密码只会发送给 Iwara，IwaraTV 不会接触。
3. IwaraTV 检测到会话后会自动关闭窗口，侧边栏会显示你的用户名。

当 Iwara 要求验证浏览器（“需要浏览器验证”）时，也使用同一个窗口。**设置 → 账号 → 退出登录**会清除 IwaraTV 中保存的 Iwara Cookie 和站点数据；收藏、历史和下载会保留。

## 作者、标签与评论

- 在视频页或作者页点击**关注**即可关注作者，其新视频会出现在订阅页。
- **关注标签**用于“关注标签”列表；**屏蔽标签**会在所有地方隐藏匹配的视频（屏蔽标签会同时取消关注）。可通过标签菜单或**设置 → 内容过滤**管理，后者还可设置筛选时扫描的页数和页面之间的间隔。
- **评论**会在视频页中加载并显示回复；登录后可以评论和回复。

## 收藏与历史

收藏保存在这台电脑上，而不是你的 Iwara 账号中。点击星标即可添加或移除视频；移除后可点击**撤销**。在**收藏**页可以筛选、排序，以及：

- **备份**：在应用数据旁写入一份副本。
- **导出…**：把 JSON 文件保存到任意位置。
- **导入…**：合并从 IwaraTV 导出的 JSON 文件；重复项会合并，并保留最早的收藏时间。

**历史**按日期分组列出你播放过的视频，并显示使用的清晰度、播放器以及在内置播放器中看了多少。可以**继续播放**（或**再次播放**）、移除单条记录或清空全部历史。

## 下载

在**设置 → 下载**中选择下载文件夹、默认清晰度、并行连接数和分段阈值。默认文件夹是“下载”文件夹中的 `IwaraTV`。

- 视频页会下载你选择的清晰度；视频卡片上的快捷下载使用默认清晰度。
- 服务器支持时，大文件会分段并行下载。
- **取消**会保留已下载的部分；**继续**会从中断处接着下载，重启应用后也可以。
- 已完成的项目提供**播放文件**和**在文件夹中显示**；**⋯** 菜单可移除记录，对已完成的下载还会询问是否同时删除文件。
- 标签页可筛选进行中、已完成和已中断（失败或已取消）的下载；**清空列表**会移除已结束的记录（文件会保留）。
- 下载进度也会显示在任务栏或程序坞图标上。IwaraTV 在后台时，下载完成或失败会弹出系统通知，点击即可打开下载页。可通过**下载完成时通知**关闭。

## 网络与故障排查

**设置 → 网络线路**用于管理 CDN 线路池。**开始测速**会从每条线路下载一小段样本；开启**使用最快线路**后，播放和下载链接会改写为排名第一的线路。如果出现 HTTP 403 错误，请关闭此选项。

视频页中的**故障排查**提供：

- **与网页版对比（抓包诊断）**：在隐藏的 Iwara 页面中打开该视频，对比网页版获得的清晰度与 IwaraTV 看到的清晰度——适用于只出现低清晰度的情况。
- **测速 CDN 线路**：使用该视频进行测速。

**设置 → 高级**显示 Iwara 用于签名文件列表请求的 X-Version 盐值。IwaraTV 每天最多从 Iwara 网站识别一次；点击**立即识别**可手动刷新。

出错时会显示带建议操作的提示，例如**登录**、**打开设置**或**重试**。

| 问题 | 处理方法 |
| --- | --- |
| “未找到 MPV” | 安装 MPV，或在**设置 → 播放**中选择 MPV 可执行文件，也可以改用外部播放器。 |
| 外部播放器无法打开 | 检查可执行文件路径，并确认参数中包含 `{url}`。 |
| “需要浏览器验证” | 点击**打开 Iwara 窗口**并完成验证。 |
| “需要登录”或“登录已过期” | 重新登录。 |
| 只有低清晰度 | 登录后使用**故障排查 → 与网页版对比（抓包诊断）**。 |
| 播放或下载时出现 HTTP 403 | 在**设置 → 网络线路**中关闭**使用最快线路**。 |
| 下载失败或停滞 | 点击**继续**，减少并行连接数，或选择其他清晰度。 |
| 导入收藏时跳过了部分条目 | 请使用从 IwaraTV 导出的 JSON 文件。 |
| “已拒绝该更新” | 文件与发布内容不一致，因此未安装任何内容。请稍后重试，或从 GitHub 下载该版本。 |

## 更新

IwaraTV 会在启动 20 秒后以及之后每 6 小时检查一次 GitHub 上的新版本。有新版本时，侧边栏的**设置**上方会出现提示，点击即可查看更新内容。

安装方式不同，更新方式也不同：

- **Windows 安装版和 AppImage：**更新在后台下载。方便时点击**重启以更新**，IwaraTV 会关闭、安装并重新启动，数据保持不变。
- **Windows 便携版和 ZIP：**点击**下载**。IwaraTV 会保存新文件（尽可能放在便携版程序旁边）并在文件夹中显示；关闭 IwaraTV 后启动新文件，或把 ZIP 解压覆盖到 IwaraTV 文件夹。
- **Linux `.deb`：**点击**下载**，然后点击**打开安装程序**，系统软件安装器可能会要求输入密码。
- **macOS：**点击**下载**，然后点击**打开磁盘映像**，把 IwaraTV 拖到“应用程序”替换旧版本。

每个文件在使用前都会与发布时公布的校验和比对；发布还可以签名，使 IwaraTV 只接受本项目发布的文件。**设置 → 更新**会显示当前版本使用的校验方式。**不兼容更新**会改变 IwaraTV 的工作方式或运行要求，这类更新绝不会自动下载或安装：更新窗口会显示警告，由你决定。**跳过此版本**可在出现更新的版本之前不再提醒。

在**设置 → 更新**中可以立即检查、关闭自动检查，以及选择是否在后台下载更新。检查更新只会访问 github.com，不发送 Cookie 或任何可识别你的信息。

## 数据存放位置

| | Windows | macOS | Linux |
| --- | --- | --- | --- |
| 应用数据 | `%APPDATA%\IwaraTV` | `~/Library/Application Support/IwaraTV` | `~/.config/IwaraTV` |

应用数据文件夹（也显示在**设置 → 高级**中）包含：

- `settings.json` — 偏好设置、标签列表、线路排名和播放历史（包括内置播放器中看到的位置）。
- `favorites.json` 和 `favorites.backup.json` — 收藏及最近一次备份。
- `downloads.json` — 下载列表。
- `window-state.json` — 窗口大小和位置。
- `Partitions/iwara` — Iwara 浏览器会话（Cookie 和站点存储），类似浏览器的用户配置。

Windows 安装版的更新下载到 `%LOCALAPPDATA%\IwaraTV-updates`，安装后会在下一次检查更新时清理；其他更新保存在“下载”文件夹中（或便携版程序、AppImage 旁边）。

从旧版导入时，如果替换了已有文件，原文件会以 `.pre-migration.json` 后缀保留。下载的视频保存在你选择的下载文件夹中。
